# 令和6年度データ追加パッケージ

## 内容
- `index.html`：科目選択が「表示」後に全科目へ戻る不具合を修正したアプリ本体
- `data/R06/`：令和6年度の午前択一・午後択一・午後記述式のデータ一式

## GitHubへの反映
1. ZIPを展開する。
2. 展開した `index.html` を、GitHubリポジトリ直下の既存 `index.html` と置き換える。
3. 展開した `data/R06/` フォルダを、リポジトリの `data/` の中へアップロードする。
4. `data/R07/` と `data/R08/` は削除・上書きしない。
5. Commit changes を押す。

## 科目選択の修正
科目を選択して「表示」を押しても、選択科目を維持するように変更。
年度・午前午後・形式の変更後も、選択科目が新しい問題集合に存在すれば維持し、存在しない場合は「全科目」に戻す。

## データ件数
- 午前択一：35問
- 午後択一：35問
- 午後記述式：2問
- 予備校解答：70問分
- PDFページ抽出：午前37ページ、午後75ページ

## 注意
解答は添付された解答一覧PDFから転記した予備校解答で、公式解答との照合は未実施。
問題文・記述式の別紙等はPDFからのテキスト抽出であり、図表・画像・複雑なレイアウトが完全に再現されない場合がある。原本PDFも併用すること。
公開GitHubへの掲載前に、試験問題・解答一覧の二次利用条件を確認すること。
