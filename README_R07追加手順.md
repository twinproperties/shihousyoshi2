# 令和7年度 追加データ v001

既存の司法書士PWAリポジトリに、令和7年度データを追加するためのファイルです。

## アップロード方法
1. ZIPを展開します。
2. 展開した `data/R07/` フォルダを、既存GitHubリポジトリの `data/` フォルダ直下にアップロードします。
3. GitHub上で `data/R07/manifest.json` と6つのCSVがあることを確認してCommitします。
4. アプリを再読み込みし、年度選択に「令和7年度」が表示されるか確認します。

`index.html`、`sw.js` などアプリ本体は変更しません。既存の `data/R08/` は削除・上書きしないでください。

## 収録内容
- 午前択一 35問
- 午後択一 35問
- 午後記述 2問（第36問・第37問）
- 予備校解答番号 70問
- PDFページ抽出テキスト 107ページ分
- 肢別抽出候補 350件（未照合）

## 注意
問題文はPDFから抽出したテキストです。図表・別紙・文字配置・一部文字の抽出崩れがあり得ます。特に記述式は原本PDFでの確認が必要です。
予備校解答はユーザー提供の一覧を登録したもので、公式解答との照合は未実施です。
GitHubの公開リポジトリにアップロードする場合、試験問題の二次利用・公開条件を確認してください。
