## GitHubへの設置
1. 新しいPublicリポジトリを作成（例：`shoshi-training`）。
2. ZIPを解凍し、フォルダの中身（`index.html`, `manifest.webmanifest`, `sw.js`, `data/`, `docs/`）をリポジトリのルートにアップロード。
3. GitHub Pagesを `main` ブランチ / root に設定。
4. `https://OWNER.github.io/REPOSITORY/` を開く。
5. 初回アクセス時、GitHub Contents APIで `data/R08/manifest.json` を検出する。

## 次年度の追加
`data/R07/` のような年度フォルダを追加し、同じCSV構成と `manifest.json` をアップロードする。アプリ本体・Service Workerは原則変更不要。GitHub APIの公開アクセス制限に達した場合は、静的な年度インデックス方式へ切替可能。

## 注意
- GitHub Pagesは公開サイト。Publicリポジトリに置いたPDF由来データ・解答は第三者も取得可能。過去問の著作権・二次利用条件を確認し、公開許諾のない本文の公開は避ける。個人専用でもPagesはアクセス制御された非公開ストレージではない。
- 予備校解答はユーザー提供情報であり、公式解答ではない。
- 肢候補は自動抽出で、全文照合・表形式・対話形式・穴埋めの意味構造確認が未完了。正誤学習の確定データとして使わない。
- PDF抽出全文を表示するため、改行や表の読み順が原本と異なる場合がある。
- 記述式は問題全文の収録であり、解答・採点基準・答案欄構造は未作成。
