# 令和5年度データ追加手順

1. ZIPを展開します。
2. GitHubリポジトリの既存 `data/` フォルダに、このZIP内の `data/R05/` フォルダをアップロードします。
3. `data/R05/manifest.json` と6つのCSVが直接入っていることを確認します（余分な階層を作らない）。
4. Commit changes を押します。
5. 既存の `data/R06/`、`data/R07/`、`data/R08/` は削除・上書きしません。
6. `index.html` の変更は不要です。通常の年度追加としてデータだけを追加します。
