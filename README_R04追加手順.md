# 令和4年度データ追加手順

1. ZIPを展開します。
2. GitHubリポジトリの `data/` フォルダを開きます。
3. 展開した `data/R04/` フォルダをアップロードします（`R04` フォルダごと）。
4. Commit changes を押します。

既存の `R05`〜`R08` は削除・上書きしません。今回の追加では `index.html` と `sw.js` の変更は不要です。
